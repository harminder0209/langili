# Project instructions

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `harminder0209/langili`.
See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`.
See `docs/agents/triage-labels.md`.
`ready-for-agent` never starts an agent. Specs never get it, and a spec issue is closed once `/to-tickets` has published its tickets.

### Domain docs

Single-context layout: root `CONTEXT.md` and `docs/adr/`.
See `docs/agents/domain.md`.
